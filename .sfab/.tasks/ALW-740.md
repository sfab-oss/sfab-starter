# ALW-740 Remove starter codemode / LOADER so fabricated apps can deploy without Dynamic Workers

## Context
ALW-738 BYO E2E Deploy failed on a free Cloudflare account with CF API **10195**: Dynamic Workers / `worker_loaders` (`LOADER`) require **Workers Paid**. Starter declares `worker_loaders: [{ binding: "LOADER" }]` and wires agent tools through `@cloudflare/think` **codemode** (`createExecuteRuntime` / `createExecuteTool`), which needs that binding.

Hypothesis (operator): **Think can stay**; drop codemode and expose ERP tools as ordinary top-level tools so LOADER is unnecessary. Goal: fabricated apps deploy without the Dynamic Workers paid feature. (Durable Objects / `OrgAgent` may still require Workers Paid — call that out in verification; do not claim free-tier if DO still blocks.)

## Scope
- Remove `worker_loaders` / `LOADER` from `apps/web/wrangler.jsonc` (+ test wrangler) and `LOADER` from env types.
- Stop using codemode execute path in OrgChat / OrgSubAgent; keep `@cloudflare/think` for the agent loop.
- Expose catalog/display tools as top-level tools (or an equivalent non-LOADER pattern) with approval gating preserved where `needsApproval` mattered.
- Remove or gut codemode-only UI (`PausedExecutionCard` / `tool-codemode`), vite `@cloudflare/codemode` plugin, and dead `codemode-output` helpers if unused.
- Update system / page-context prompts that tell the model to use `codemode.*`.
- Update BYO / starter docs that imply Dynamic Workers / LOADER is required for the template.

## Acceptance criteria
- [ ] AC-1: `apps/web/wrangler.jsonc` has no `worker_loaders` / `LOADER`; types and docs match. verify: `rg worker_loaders|LOADER apps/web packages/env`
- [ ] AC-2: Org agent chat still works via Think without a `codemode` tool — reads/writes go through top-level tools (or documented replacement). verify: local chat smoke + unit/workerd tests updated
- [ ] AC-3: Destructive tool approval path still works without mid-codemode pause (or equivalent UX). verify: existing approval tests adapted
- [ ] AC-4: A fabricate → Deploy attempt no longer fails with Dynamic Workers / code 10195 for missing LOADER. verify: Deploy log or wrangler dry-run; note separately if DO paid plan still blocks

## Non-goals
- Removing `@cloudflare/think` or the OrgAgent / OrgChat DO pattern.
- Changing the platform factory’s own LOADER/codemode usage (`apps/platform`).
- Claiming free-tier deploy if Durable Objects alone still require Paid.

## Boundaries
- ✅ Always: starter-only; preserve Think agent loop; honest docs about remaining paid prerequisites.
- ⚠️ Ask first: large UX redesign of tool cards beyond what’s needed to drop codemode.
- 🚫 Never: leave a dead LOADER binding “for later”; ship half-removed codemode that still imports execute runtime.
