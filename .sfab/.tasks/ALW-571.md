# ALW-571 i18n: localize registry block demo copy (follow-up to ALW-457)

## Context

[[ALW-457]] ships app-only multi-language (Paraglide, EN+ES, cookie switcher, sync/lint, agent skill). Registry blocks under `packages/registry` still carry English (and occasional mixed) demo copy and are a parallel string surface when installed via shadcn add.

## Scope

- Bring registry block / demo user-visible strings onto the same catalog conventions as ALW-457 (or a documented registry-local variant).
- Ensure installable blocks do not reintroduce hardcoded English-only chrome that fights the app locale.
- Update registry README / skill notes if installers need an extra i18n step.

## Acceptance criteria

- [ ] AC-1: Primary registry blocks used by the live app/gallery have message catalogs (or shared app catalogs) for EN+ES. verify: inspect registry messages + gallery smoke.
- [ ] AC-2: i18n:lint (or registry equivalent) covers registry catalogs or documents an explicit exclusion list. verify: run lint path.
- [ ] AC-3: Docs note how pack/block authors add copy without hardcoding. verify: read guide/skill update.

## Non-goals

- Replacing ALW-457 app i18n.
- Translating every historical demo string in one PR if sliced follow-ups are clearer.
- TMS integration.

## Boundaries

- Always: stay consistent with ALW-457 catalog-first rules; no API keys in repo.
- Ask first: changing registry item public API / install contract for i18n.
- Never: break shadcn add install paths.
