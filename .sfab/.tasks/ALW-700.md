# ALW-700 Starter: @workspace/log + migrate server console + noConsole (V1 light)

## Context

[[ALW-673]] decided: **V1 = light ops logging** only (not ERP activity UI). Platform precedent is [[ALW-662]] `@sfab/log` + [[ALW-671]] `noConsole`. Starter still has ~11 server-side raw `console.*` sites (hono / email / org-chat) and `hono/logger()`; client chat/UI consoles stay out of scope. This is the deferred half of [[ALW-672]].

## Scope

- Add zero-dep `@workspace/log` (copy/adapt `@sfab/log` shape: `structuredLog`, `errorMessage`, typed `LOG_KINDS`).
- Starter-scale kind vocabulary only (~10–15), not platform’s ~180 ops kinds.
- Migrate server call sites under `apps/web/src/hono/**`, `packages/email/**`, `packages/agent/**` to the helper.
- Short `docs/engineering/structured-logging.md` (envelope + kinds + enforcement).
- Enable Biome `suspicious/noConsole: error` with carve-outs for client UI (`apps/web` components/routes/hooks, `packages/ui`), the helper module, scripts/tests — matching platform pattern.
- **`hono/logger()`**: keep for V1 (starter has no `request_log` middleware yet). Optional thin `request_log` is a follow-up, not required here.

## Acceptance criteria

- [ ] AC-1: `@workspace/log` exists with unit tests for `structuredLog` / `errorMessage`. verify: package tests pass
- [ ] AC-2: Zero raw `console.*` in server scan scope (hono, email, agent) outside the helper. verify: `pnpm lint:check` with `noConsole`
- [ ] AC-3: `docs/engineering/structured-logging.md` documents envelope + starter `LOG_KINDS`. verify: doc present
- [ ] AC-4: Biome `noConsole` is error with documented client/helper carve-outs. verify: root `biome.jsonc`

## Non-goals

- Persisting logs to D1 / activity tables / UI activity tabs ([[ALW-699]]).
- Migrating client/browser `console.*` in chat UI or `packages/ui`.
- Removing `hono/logger()` or adding request wide-event middleware.
- Changing platform `@sfab/log`.

## Boundaries

- ✅ Always: secret-free payloads; prefer `error: errorMessage(err)`; keep package out of `@workspace/core`.
- ⚠️ Ask first: dropping `hono/logger()` without a replacement; enabling `noConsole` on client paths.
- 🚫 Never: log tokens/cookies; conflate ops logs with user-facing activity events.
