# ALW-830 Bump starter wrangler 4.124 + Cloudflare vite-plugin 1.53

## Context

Follow-up to [[ALW-828]] (Vite 8). Starter stayed on `wrangler@4.107` and `@cloudflare/vite-plugin@1.43` because plugin 1.53 peers `wrangler ^4.124`. Owner asked to do that bump now. Age-eligible (2-day `minimumReleaseAge`): wrangler **4.124.0**, plugin **1.53.0**. Latest wrangler 4.125.0 / plugin 1.53.1 are too new.

## Scope

- Pin exact age-eligible versions in web and docs:
  - `wrangler@4.124.0`
  - `@cloudflare/vite-plugin@1.53.0`
  - `@cloudflare/vitest-pool-workers@0.22.0` (depends on wrangler 4.124.0; previously left at 0.16.20 to avoid nesting a newer wrangler)
  - docs `@cloudflare/workers-types` to an age-eligible 5.x that satisfies wrangler 4.124's peer `^5.20260815.1` (currently docs is on v4)
- Keep Vite 8 / TanStack / Table v9 / AI SDK pins. Keep `zod@4.3.5`.
- Discard typegen noise (`worker-configuration.d.ts`, `packages/env/src/env.d.ts`) unless the generator change is a real type contract the app needs.
