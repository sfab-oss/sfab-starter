# ALW-830 Bump starter wrangler 4.124 + Cloudflare vite-plugin 1.53

## Context

Follow-up to [[ALW-828]] (Vite 8). Starter stayed on `wrangler@4.107` and `@cloudflare/vite-plugin@1.43` because plugin 1.53 peers `wrangler ^4.124`. Owner asked to do that bump now. Age-eligible (2-day `minimumReleaseAge`): wrangler **4.124.0**, plugin **1.53.0**. Latest wrangler 4.125.0 / plugin 1.53.1 are too new.

## Scope

- Pin exact age-eligible versions in web and docs:
  - `wrangler@4.124.0`
  - `@cloudflare/vite-plugin@1.53.0`
  - `@cloudflare/vitest-pool-workers@0.22.0` (depends on wrangler 4.124.0; previously left at 0.16.20 to avoid nesting a newer wrangler)
  - docs `@cloudflare/workers-types` to an age-eligible 5.x that satisfies wrangler 4.124's peer `^5.20260815.1` (currently docs is on v4)
- Keep Vite 8 / TanStack / Table v9 / AI SDK pins. Keep `zod@4.3.5`.
- Discard typegen noise (`worker-configuration.d.ts`, `packages/env/src/env.d.ts`) unless the generator change is a real type contract the app needs.

## Acceptance criteria

- [ ] AC-1: web and docs pin `wrangler@4.124.0` and `@cloudflare/vite-plugin@1.53.0`. verify: package.json
- [ ] AC-2: web pins `@cloudflare/vitest-pool-workers@0.22.0`. verify: package.json
- [ ] AC-3: `pnpm install` succeeds under `minimumReleaseAge: 2880`. verify: install
- [ ] AC-4: `pnpm typecheck`, `pnpm lint:check`, `pnpm test` green. Typegen not committed unless required. verify: those commands
- [ ] AC-5: `pnpm --filter web build` and `pnpm --filter docs build` succeed. verify: those builds
- [ ] AC-6: Draft PR from `alw-###-wrangler-plugin` against `sfab-oss/sfab-starter` `main`.

## Non-goals

- Vite, TanStack, Table, AI SDK. Product/UI changes. Raising `engines.node` unless the bump forces it.
- wrangler 4.125 / plugin 1.53.1 (too new for the 2-day gate).

## Boundaries

- ✅ Always: packet worktree; exact age-eligible pins; discard typegen noise.
- ⚠️ Ask first: committing generated env/worker types; merging; engines.node bump.
- 🚫 Never: push to `main`; float zod; `wrangler … --remote`.
