# ALW-494 [Group] Lint &amp; logging conventions — own Biome ruleset, smell gates, structured logging

## Context

Both repos extended Ultracite on Biome 2.3.x. This Group owned taking the ruleset in-house — fork the presets into a workspace package, bump Biome, drop Ultracite — then adding smell lint gates on top. It has since become the home for the **starter logging convention** work as well, which is adjacent (both are "conventions enforced by tooling") but was not in the original charter.

**The Biome half is complete.** Ruleset ownership landed in the starter ([[ALW-495]]) and the platform ([[ALW-498]]); smell gates followed as [[ALW-671]] (platform: `useEffect` justify + `noConsole`) and [[ALW-672]] (starter: `useEffect` gate, `noConsole` deferred). [[ALW-496]] was withdrawn — superseded by 671/672 doing the work directly.

**The logging half is in flight.** [[ALW-700]] shipped `@workspace/log` and migrated server console calls with `noConsole` (V1 ops-light), leaving [[ALW-673]] (the convention itself) and [[ALW-699]] (wire real `activity_log` to the document ActivityTimeline, V2) still active.

Note this Group spans both repos: [[ALW-498]] and [[ALW-671]] are `sfab` platform tasks parented to a `sfab-starter` Group, deliberately — the ruleset decision was one decision applied twice.

## Settled decisions

- **Order:** starter → platform → smell gates. Followed.
- **Fork:** Ultracite 7.9.3+ `core` + `react` + `tanstack`; `next` dropped.
- **Shape:** `@workspace/biome-config` (starter) and its platform analogue; root `biome.jsonc` extends and overrides.
- **Trim:** parity exit on the first PRs.
- **Logging:** V1 is ops-light (structured server logging, `noConsole`); V2 is domain activity, which is where 699 sits.
