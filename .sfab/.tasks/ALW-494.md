# ALW-494 [Group] Lint &amp; logging conventions — own Biome ruleset, smell gates, structured logging

## Context

Both repos extended Ultracite on Biome 2.3.x. This Group owned taking the ruleset in-house — fork the presets into a workspace package, bump Biome, drop Ultracite — then adding smell lint gates on top. It also absorbed the starter **structured logging** convention work (adjacent: conventions enforced by tooling).

**Complete as of 2026-07-24.** All children landed (7 done, 1 withdrawn). Follow-on debt from the smell gates — auditing the `biome-ignore` placeholders they introduced — lives outside this Group as [[ALW-695]] (starter) and [[ALW-696]] (platform).

Note this Group spanned both repos: [[ALW-498]] and [[ALW-671]] are `sfab` platform tasks parented to a `sfab-starter` Group, deliberately — one ruleset decision applied twice.

## Settled decisions

- **Order:** starter → platform → smell gates. Followed.
- **Fork:** Ultracite 7.9.3+ `core` + `react` + `tanstack`; `next` dropped.
- **Shape:** `@workspace/biome-config` (starter) and its platform analogue; root `biome.jsonc` extends and overrides.
- **Trim:** parity exit on the first PRs.
- **Logging:** V1 is ops-light (structured server logging, `noConsole`); V2 is domain activity ([[ALW-699]]).
