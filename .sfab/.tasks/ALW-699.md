# ALW-699 Starter: wire real activity_log to document ActivityTimeline

## Context

[[ALW-673]] / [[ALW-700]] split ops logs (`@workspace/log` → Workers Logs) from ERP activity. Starter **already** persists domain events in `activity_log`, exposes `listActivity` + `GET /documents/activity`, and shows a plain list on `/documents/$id`. Registry Collect blocks still use **mock** timelines (gallery only). This task closes the product loop: registry-aligned timeline UI on real `activity_log` data.

## Scope

- Promote/adapt `ActivityTimeline` into `apps/web` document UI (not full Collect install).
- Map `activity_log` rows → timeline entries (`eventType`/`summary`/`createdAt`/`actorId`).
- Replace the hand-rolled activity list on `/documents/$id` with `ActivityTimeline`.
- Fix TanStack Query invalidation so finalize/payment refresh document activity.
- Short doc note: ops logs ≠ activity (cross-link structured-logging).
- Optional: activity strip inside `RecordPaymentDialog`.

## Acceptance criteria

- [ ] AC-1: Written distinction ops (`@workspace/log`) vs activity (`activity_log`) in engineering docs or task-linked note. verify: doc present
- [ ] AC-2: Document activity API remains the source; UI reads it (not mocks, not Workers Logs). verify: `/documents/$id` uses `useActivity` → mapped entries
- [ ] AC-3: After accept → finalize → pay, timeline shows real events (e.g. accepted / finalized / payment_recorded). verify: browser walkthrough or test
- [ ] AC-4: Finalize and record-payment mutations invalidate the document activity query. verify: code + manual or test

## Non-goals

- New D1 schema (already exists).
- Replacing `@workspace/log` / `noConsole`.
- Full SOX audit, notes POST API, entity-page activity, installing Collect blocks into apps/web.
- Changing registry gallery mocks (demos stay mock).

## Boundaries

- ✅ Always: UI reads `activity_log` via existing API; keep ops and activity sinks separate.
- ⚠️ Ask first: moving ActivityTimeline into `@workspace/ui`; schema migrations.
- 🚫 Never: dump ops errors into the timeline; wire UI to Workers Logs.
