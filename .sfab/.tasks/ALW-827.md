# ALW-827 Bump starter to AI SDK 7 + matching Cloudflare Think/agents

## Context

`sfab-starter` is still on AI SDK 6.0.221 (`ai`, `@ai-sdk/react` 3.x, provider packages on the v6 line) and Cloudflare `agents@0.17.3` / `@cloudflare/think@0.12.1`. AI SDK 7 has been current since 2026-06-25; Cloudflare Think/agents dual-support v6 and v7 since 2026-07-23 (`ai@^6 || ^7`, pair with `@ai-sdk/react` v4). The org agent is Think (`OrgChat` / `useAgentChat` from `@cloudflare/think/react`), not `ToolLoopAgent`.

Owner chose this as PR 1 of a starter dep refresh: go to 7 now, do not spend a PR catching up 6.0.221 → 6.0.261. Pin versions that pass the repo's 2-day `minimumReleaseAge` (do not use `@latest`).

## Scope

- Pin age-eligible AI SDK 7 + matching majors: `ai@7.0.68`, `@ai-sdk/react@4.0.71`, `@ai-sdk/openai@4.0.43`, `@ai-sdk/google@4.0.45`, `@ai-sdk/openai-compatible@3.0.31` (or newer that still pass the 2-day gate at install time).
- Bump Cloudflare together (Think 0.16 requires `agents >= 0.20.2`): `agents@0.21.0`, `@cloudflare/think@0.16.0`, `@cloudflare/shell@0.4.3`.
- Run `npx @ai-sdk/codemod v7` and fix remaining type/test breaks.
- Rename `experimental_transcribe` → `transcribe` in `apps/web/src/hono/org-protected/transcribe.ts`.
- Keep Think APIs as they are (`beforeTurn` `{ system }`, `onStepFinish`, `needsApproval` on `defineOrgTool` / `delete_product`) unless typecheck or tests force a move.
- Keep `zod@4.3.5` exact. Do not float it.
- Keep `engines.node` at `>=20` unless install/CI actually fails.

- Wrangler / `@cloudflare/vite-plugin` bump (typegen noise; follow-up).
- better-auth, biome, lucide-react unification, drizzle.
- Adopting `ToolLoopAgent`, `WorkflowAgent`, AI SDK harnesses, or new telemetry.
- Migrating `needsApproval` → `toolApproval` unless the bump forces it.
- Changing org-agent product behavior, models, or prompts.
- Platform (`sfab`) AI SDK bump. Starter is the template; platform stays on 6 until its own task.
