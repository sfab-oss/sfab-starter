# ALW-743 Starter wrangler: __SFAB_*__ placeholders + drop preview_bucket_name

## Context

BYO fabricate inject today uses `jsonc-parser` `modify` on English placeholders and never rewrites Worker `"name"`. Live E2E ([[ALW-738]]) showed (1) every app deploys as Worker `sfab-starter` and (2) inject reformats untouched `migrations` → first CI Biome-red. Sharpen locked an ideal: template ships named `__SFAB_*__` tokens; platform fills them format-stably ([[ALW-744]]). This task is **starter-only** and must merge first.

Sharpen intake: `active/alw-738-byo-e2e-resume/artifacts/sharpen-intake/` · exploration: `artifacts/explorations/wrangler-inject-architecture.md`.

## Scope

- In `apps/web/wrangler.jsonc` (and test wrangler if present), replace live/English project-owned scalars with tokens:
  - `name` → `__SFAB_WORKER_NAME__`
  - `account_id` → `__SFAB_ACCOUNT_ID__` (add if absent)
  - D1 `database_id` / `database_name` → `__SFAB_D1_DATABASE_ID__` / `__SFAB_D1_DATABASE_NAME__`
  - R2 `bucket_name` → `__SFAB_R2_BUCKET_NAME__`
- Drop `preview_bucket_name` from R2 binding (no shared preview bucket).
- Keep comments, migrations, DO bindings, and Biome shape otherwise unchanged.
- Update any starter docs/tests that assert the old placeholder strings or `sfab-starter` as the deployable Worker name for fabricated apps (template repo itself may still document local-dev overrides).
- Do **not** change platform inject code ([[ALW-744]]).

## Acceptance criteria

- [ ] AC-1: `apps/web/wrangler.jsonc` uses the locked `__SFAB_*__` tokens for worker name, account_id, D1 id/name, R2 bucket name. verify: `rg '__SFAB_' apps/web/wrangler.jsonc`
- [ ] AC-2: No `preview_bucket_name` in starter wrangler. verify: `rg preview_bucket_name apps/web`
- [ ] AC-3: `pnpm lint:check` (or repo equivalent) passes — Biome still happy with migrations compact form. verify: CI / local lint
- [ ] AC-4: Draft PR on branch `alw-743-…` linked to this task.

## Non-goals

- Platform fill engine, Worker ledger/teardown, provision-from-template ([[ALW-744]]).
- Seed-time fill; ALW-311 incremental provision; renaming leftover CF Workers.
- Removing Think/DOs; changing Deploy workflow.

## Boundaries

- ✅ Always: tokens exactly as sharpened (`__SFAB_WORKER_NAME__`, `__SFAB_ACCOUNT_ID__`, `__SFAB_D1_DATABASE_ID__`, `__SFAB_D1_DATABASE_NAME__`, `__SFAB_R2_BUCKET_NAME__`); keep comment-preserving human-authored wrangler shape.
- ⚠️ Ask first: renaming tokens; adding extra placeholders beyond the locked set.
- 🚫 Never: leave English `placeholder-remote-db-id` / `sfab-starter` as the fabricated identity fields; push to `main`.
