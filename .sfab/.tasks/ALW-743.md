# ALW-743 Starter wrangler: sfab-tok-* placeholders + drop preview_bucket_name

## Context

BYO fabricate inject today uses `jsonc-parser` `modify` on English placeholders and never rewrites Worker `"name"`. Live E2E ([[ALW-738]]) showed (1) every app deploys as Worker `sfab-starter` and (2) inject reformats untouched `migrations` → first CI Biome-red. Sharpen locked format-stable template tokens; platform fills them ([[ALW-744]]). This task is **starter-only** and must merge first.

**Token spelling (amended 2026-07-26):** Wrangler rejects `__SFAB_*__` (uppercase/underscores) for `name` / `bucket_name`. Use wrangler-valid `sfab-tok-*` tokens instead.

Sharpen: `active/alw-738-byo-e2e-resume/artifacts/sharpen-intake/`.

## Scope

- In `apps/web/wrangler.jsonc` (and test wrangler if present), set:
  - `name` → `sfab-tok-worker-name`
  - `account_id` → `sfab-tok-account-id` (add if absent)
  - D1 `database_id` / `database_name` → `sfab-tok-d1-database-id` / `sfab-tok-d1-database-name`
  - R2 `bucket_name` → `sfab-tok-r2-bucket-name`
- Drop `preview_bucket_name` from R2 binding.
- Keep comments, migrations, DO bindings, and Biome shape otherwise unchanged.
- Update docs/tests that asserted old English placeholders or `__SFAB_*__`.
- Do **not** change platform inject code ([[ALW-744]]).

## Acceptance criteria

- [ ] AC-1: `apps/web/wrangler.jsonc` uses the locked `sfab-tok-*` tokens above. verify: `rg 'sfab-tok-' apps/web/wrangler.jsonc`
- [ ] AC-2: No `preview_bucket_name` in starter wrangler. verify: `rg preview_bucket_name apps/web`
- [ ] AC-3: Tip is buildable — wrangler config validates `name`/`bucket_name`; `pnpm lint:check` (+ typecheck/build as required by hooks) passes. verify: CI / local
- [ ] AC-4: Draft PR on branch `alw-743-…` linked to this task.
