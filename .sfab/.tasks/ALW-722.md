# ALW-722 Replace six safe useEffects (useSyncExternalStore / event handlers / callback refs)

## Context

[[ALW-695]] audited biome-ignored `useEffect` sites and removed four redundant syncs. A stricter follow-up pass (`artifacts/explorations/useeffect-strict-pass.md` in the ALW-695 packet) identified nine REPLACE candidates. This task is **PR-A only**: the six localized, low-risk replacements. ChatWindow parent bridges and MAYBE/KEEP sites are out of scope.

## Scope

Replace these six sites (behavior-identical):

- `packages/ui/src/hooks/use-mobile.ts` — matchMedia → `useSyncExternalStore`
- `packages/ui/src/components/ai-elements/chat-voice-button.tsx` — MediaRecorder support → `useSyncExternalStore` (`getServerSnapshot: () => false`)
- `packages/registry/registry/_shared/preview-state-dock.tsx` — drag `pointermove`/`pointerup` in start/end handlers (prefer `setPointerCapture` if clean)
- `apps/web/src/components/documents/draft-line-editor.tsx` — compose focus via callback ref; Escape via start/cancel listeners
- `packages/ui/src/components/brand/pdf-viewer.tsx` — ResizeObserver via callback ref
- `apps/web/src/components/chat/memory/memory-card.tsx` — overflow ResizeObserver via callback ref

Remove the corresponding `biome-ignore lint/plugin/no-use-effect` (or layout-effect) comments when the effect is gone. Update `docs/engineering/code-smells.md` with at least one new fixed reference if helpful.

## Acceptance criteria

- [ ] AC-1: All six listed sites no longer use `useEffect`/`useLayoutEffect` for the replaced pattern. verify: `rg` shows no biome-ignore on those call sites; lint green
- [ ] AC-2: Behavior preserved (hydration-safe mobile/voice; drag cleanup; focus/Escape on compose; ResizeObserver attach/detach). verify: `pnpm typecheck` + `pnpm lint:check` + `pnpm test`
- [ ] AC-3: No ChatWindow bridge refactors and no MAYBE/KEEP site changes.

## Non-goals

- ChatWindow status/messages/connectionStatus bridges (PR-B).
- MAYBE sites (markdown-editor policy, page-context, TipTap lift, code-block `use()`, org/workspace → RQ, pending flush).
- KEEP sites (keydown shortcuts, timers, TipTap setEditable, Univer, query invalidation).
- Platform repo / [[ALW-696]].

## Boundaries

- ✅ Always: prefer React-recommended patterns; keep SSR/hydration snapshots matching prior first paint (`false` where applicable).
- ⚠️ Ask first: any change that alters UX timing (focus/scroll/animation) beyond the listed replacements.
- 🚫 Never: disable the Biome gate; blanket-delete unrelated ignores; touch chat-window bridges.
