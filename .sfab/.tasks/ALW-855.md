# ALW-855 Starter IA reconciliation: live Catalog/Entities/Documents is the truth; demote operator-ux; fix registry phantom routes

## Context
The starter carries two information architectures: the live app (Catalog / Entities / Documents, `apps/web/src/components/layout/platform-navigation.ts`) and a spec (`docs/architecture/operator-ux.md`: Hoy / Vender / Cobrar / Comprar) plus a registry nav (`packages/ui/src/lib/navigation-config.ts`) pointing at `/sell`, `/collect`, `/buy`, `/people` — routes that do not exist. An unsupervised agent follows the louder spec and builds the wrong shell. Direction 04 (owner, 2026-08-31): **generic worldwide ERP as the base; packs add country/vertical specifics; i18n handles language.** The live IA is the truth. This is one of the first jobs to run through the Factory loop.

## Scope
- Rewrite `docs/architecture/operator-ux.md` into a short candidate-pack note (what a Mexican-SME operator pack would add on top of the generic base); remove "target IA" language.
- Fix `navigation-config.ts` to the routes that exist (or remove the phantom entries); make registry/gallery nav agree with app nav.
- `docs/architecture.md`: drop the old→new package-name migration text; remove the MCP surface claim (no MCP server under `apps/web`); state the generic-base + packs + i18n shape in one paragraph.
- Do not build packs; note that the pack mechanism (ADR-0010/0017, `sfabKind: "pack"`) is unbuilt and lives on the roadmap.
