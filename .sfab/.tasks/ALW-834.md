# ALW-834 UX a11y, i18n leftovers, and chat chrome

## Context

[[ALW-482]] / [[ALW-428]] walk (2026-08-21) completed the keyboard pass login → catalog → invoice → payment → chat. The path is completable, but several chrome/copy issues remain: Home vs Today, Spanish leftovers, login tab order, unlabeled desktop chat buttons, and icon-only theme/language controls.

## Scope

- Align Home: nav label, breadcrumb, and Spanish (`Hoy > Hoy` today). Welcome cards should include Entities or drop it from nav if it is not a first-class destination.
- Auth: language switcher on forgot-password and reset-password, same as login/signup. Invalid reset token heading matches the invalid state (not "Choose a new password").
- Login tab order: Email then Password, with Forgot password not between them.
- Catalog sort popover: unique accessible names (not two "Ascending" / "Descending" pairs). Payment method and Add Entity type comboboxes have accessible names.
- Desktop chat dock header buttons have names matching mobile (Minimize, Show files, More, Close). Opening New chat moves focus into the composer. Dock should not cover the page primary CTA (members Send Invitation). Overflow menu text should not wrap mid-word.
- Org switcher: theme and language are not icon-only; org initials are consistent (`DE` vs `D`).
- Members: do not offer Leave for the sole Owner (or confirm it is blocked). Invite placeholder is a generic email, not `elon@spacex.com`. ES: translate settings "General", members "Avatar", and brand "Starter" or keep them intentionally untranslated everywhere.
- Documents list keyboard: reaching the first row should not require tabbing every column-sort header (or those headers skip in a sensible way).

## Acceptance criteria

- [ ] AC-1: Home nav and breadcrumb use the same label in EN and ES. Welcome includes Entities or nav does not. verify: `/` in `en` and `es`
- [ ] AC-2: Forgot and reset password show the language switcher. Invalid reset is not titled "Choose a new password". verify: `/forgot-password`, `/reset-password`
- [ ] AC-3: Keyboard login tabs Email → Password without hitting Forgot in between. New chat then Tab (or auto-focus) reaches the composer. verify: keyboard pass login → chat
- [ ] AC-4: Desktop chat header buttons expose accessible names. Sort menu items are unique. verify: snapshot of chat dock + catalog sort
- [ ] AC-5: ES settings Members has no leftover English on General/Avatar, or those strings are English in every locale on purpose. Invite placeholder is generic. verify: locale ES screenshot of settings

## Non-goals

- Layout density, payment overflow, 404 page (siblings).
- Full WCAG audit or skip-link design beyond the login field order and chat focus.
- Live agent replies or approval cards.
- Changing Owner leave policy in the API if the UI already no-ops; just do not offer a dead red action.

## Boundaries

- ✅ Always: keyboard pass the login → catalog → invoice → payment → chat path after the change.
- ⚠️ Ask first: adding a skip-to-main link on every protected page (nice, not required here).
- 🚫 Never: drive Leave as the demo owner against the seed org.
