# ALW-772 Refresh Cloudflare agent skills + curated MCP for template agents

## Context
Starter ships vendored Cloudflare agent skills from ~2026-03 that have drifted from [cloudflare/skills](https://github.com/cloudflare/skills). The template is Workers + D1/R2 + Durable Objects + Agents SDK (Think/Codemode/Shell) heavy, but lacks the dedicated `agents-sdk` skill and has no project-scoped Cloudflare MCP config. Agents building on the template should get current guidance without installing the entire Cloudflare pack.

## Scope
- Replace `.agents/skills/{cloudflare,wrangler,durable-objects,workers-best-practices}` with current copies from `cloudflare/skills`.
- Add `.agents/skills/agents-sdk` from the same source; symlink under `.claude/skills/` and `.agent/skills/`.
- Add curated `.cursor/mcp.json` with `cloudflare-docs`, `cloudflare-bindings`, `cloudflare-observability` (not the full five-server set).
- Update `AGENTS.md` / `.claude/CLAUDE.md` skill index to include `agents-sdk`.

## Acceptance criteria
- [ ] AC-1: The four existing Cloudflare skills under `.agents/skills/` match current `cloudflare/skills` content for those skill names. verify: compare SKILL.md (and trees) to upstream.
- [ ] AC-2: `agents-sdk` is present under `.agents/skills/` with `.claude` / `.agent` symlinks. verify: `ls -la`.
- [ ] AC-3: `.cursor/mcp.json` lists only docs + bindings + observability Cloudflare MCP URLs. verify: file contents.
- [ ] AC-4: `AGENTS.md` and `.claude/CLAUDE.md` list `agents-sdk` in the skills index and stay byte-identical. verify: `cmp AGENTS.md .claude/CLAUDE.md`.
- [ ] AC-5: Non-Cloudflare template skills (`ai-sdk`, `i18n`, `shadcn`, etc.) are unchanged.

## Non-goals
- Installing the full Cloudflare skills pack (sandbox-sdk, cloudflare-one, web-perf, turnstile, email-service).
- Adding `cloudflare` account API or builds MCP servers.
- Changing application code, wrangler bindings, or dependencies.
- Refreshing the same skills in `sfab` / `sfab-lite` (starter-only).

## Boundaries
✅ Always: source skills from github.com/cloudflare/skills; keep `.agents` as canonical with symlinks.
⚠️ Ask first: adding more MCP servers or extra skills beyond the curated five.
🚫 Never: hand-edit `.sfab/.tasks/*`; push to `main`; install unrelated Cloudflare One / SASE skills.
