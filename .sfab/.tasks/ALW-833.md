# ALW-833 UX layout: lists, details, dialogs, mobile chrome

## Context

[[ALW-482]] walk (2026-08-21) found density and dialog issues on catalog, entities, documents, and settings. Highest user-facing: Record payment overflows on a 390-wide viewport (Close sits on Cancel, Pay off-canvas, Balance clipped). Lists of 2–3 rows fill the viewport. Product detail has no page title/SKU/image. Add Product primary is "Save Changes". Invoice/quote headings duplicate the type badge.

## Scope

- Record payment dialog usable at 390px: actions visible, totals not clipped, one close path. Align method/amount formatting with the rest of the money UI (`Cash`, `$125.00`). Named combobox. Prefer the same CTA placement as other dialogs.
- Catalog / entities / documents tables do not stretch a handful of rows across the full viewport; pagination is not stranded in empty space. One clear-filters path (today there are three). Filter popover should not cover the Name column.
- Product detail: visible title (not only breadcrumb), SKU, and a non-empty media treatment. Invoice/quote: stop doubling the type as heading + badge. Empty Activity starts collapsed. Quote unit price is a 2-decimal value, not a float like `19.989999771118164`.
- Add Product primary is a create label (Add Entity already says Create Entity).
- Mobile: invoice header (sidebar + breadcrumb + Create credit note) does not collide; catalog pagination is not hidden under Ask the assistant; chat launcher is present on Home. Dark-mode input borders have readable contrast.

## Acceptance criteria

- [ ] AC-1: Record payment at 390×844: Pay, Cancel, and Close do not overlap; Total/Paid/Balance are fully visible. verify: screenshot of unpaid invoice payment dialog
- [ ] AC-2: Catalog/entities/documents with seed data (2–3 rows) no longer look like an empty page with a footer. verify: desktop screenshots of the three lists
- [ ] AC-3: Product detail shows name + SKU without opening Edit. Invoice heading is not "Invoice" plus an Invoice badge. verify: `/catalog/seed-prod-widget` and `/documents/seed-doc-invoice-contoso`
- [ ] AC-4: Add Product primary is not "Save Changes". verify: open the dialog from catalog
- [ ] AC-5: Mobile invoice header and catalog pagination are usable with the assistant bar visible; Home shows the chat launcher. verify: 390px screenshots of Home, catalog, invoice

## Non-goals

- Error/loading/org-restore states (sibling task).
- i18n leftovers, login tab order, unlabeled chat header buttons.
- Redesigning the data model or adding product images to seed if storage is out of scope; a placeholder treatment is enough.
- Changing payment allocation logic.

## Boundaries

- ✅ Always: check desktop 1440 and mobile 390; payment dialog is the regression hotspot.
- ⚠️ Ask first: changing Record payment field semantics (partial pay, methods).
- 🚫 Never: drive a real payment against non-seed data; skip the mobile payment screenshot.
