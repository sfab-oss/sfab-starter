# ALW-482 UX layout review — screens, dialogs, empty states

## Context

A focused **UX layout review** of the starter as a stranger sees it: screens, dialogs, empty states, and density — not another functional QA sweep. File confirmed layout issues as draft fix tasks; do not fix inside this session unless trivial and approved.

This was originally the last gate of the launch cut, carrying a go/no-go on [[ALW-479]]. **The starter has since launched publicly**, so that gate is gone. **Overlap to settle before dispatch:** [[ALW-428]] (cross-cutting UX — theming, states, responsive, a11y, i18n) covers adjacent ground. They are plausibly **one session rather than two** — decide at pickup whether to merge them, and if so, fold 428's scope in here rather than running both.

## Scope

Walk desktop (and spot-check mobile) across:
- Shell: sidebar, org switcher, breadcrumbs, command palette chrome
- Auth: login / signup / password reset
- Catalog list + detail; Entities list + detail
- Documents list + composer / detail; Record Payment dialog
- Settings (general + members)
- Org-agent chat: dock, approval card, history, files sheet, common dialogs

Look for: inconsistent spacing/padding, cramped or sparse layouts, dialog width/overflow, misaligned actions, competing hierarchy, broken empty states, mobile sheet issues.
